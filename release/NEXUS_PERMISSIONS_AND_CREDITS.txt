MAIN FILE DESCRIPTION - COPY THIS BLOCK

Extract the entire ZIP and open Start Dungeons II Camera Mod.cmd. Launch the
game normally, enter camp or a level, then click Start helper and press F6 to
enable first person. Stop an older helper with F10 before starting this version.
Python is included; no game files need replacing.

Preview11 updates the name and documentation; gameplay is unchanged from
Preview10. F3 / triple-click L3 switches first/third while the custom camera is
active. Supported profiles: Steam build 25647713 and Xbox/Minecraft Launcher/
Microsoft Store GDK 1.1.1.0. Local Xbox walking, arm turning, armor and menu tests
passed; broader play testing remains open. Epic and future builds are unverified.

If the camera gets stuck, F5 restores the view and F10 stops the helper. If the
game itself crashes, reopen the game. Please report recurring problems with
your mod version, controls, store and solo/co-op role. This beta does not
guarantee that restarting only the helper will fix every error.

END FILE DESCRIPTION BLOCK
